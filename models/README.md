## Model Artifacts

Place trained model artifacts from `stock_trading_bot.py train` in this folder.

Required:
- `nifty_xgb_model.pkl` (or `xgb_model.pkl`)
- `nifty_scaler.pkl` (or `scaler.pkl`)
- `nifty_features.pkl` (or `feature_cols.pkl`)

Optional:
- `nifty_lgb_model.pkl` (or `lgb_model.pkl`)
- `nifty_cat_model.pkl` (or `cat_model.pkl`)
- `nifty_tcn_model.keras` (or `tcn_model.keras`)

The backend now supports both naming conventions.
